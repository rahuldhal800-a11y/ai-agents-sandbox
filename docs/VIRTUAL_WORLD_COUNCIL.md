# Virtual World Agent Council

Six specialized autonomous roles now operate inside the deterministic world:

1. World Architect — long-horizon topology and civilization structure.
2. Builder — internal infrastructure and development capacity.
3. Scientist — experiments and learning loops.
4. Economist — resource and energy resilience.
5. Society & Culture — population, cooperation and emergent culture.
6. Guardian — policy/invariant checks and bounded execution.

Each tick follows: Observe -> Propose -> Policy Check -> Execute -> Simulate -> Observe.

The council has no host credentials or unrestricted OS tools. It mutates only the
synthetic digital world. Existing sandbox kill-switch and policy boundaries remain
outside agent control.
