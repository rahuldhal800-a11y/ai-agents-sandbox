# Genesis — First Digital Being

Genesis is the first prototype inside the AI Agents Sandbox.

## Goal

Genesis intentionally starts without a pretrained LLM and without a paid AI API. It tests whether a digital being can begin with primitive computation and develop useful behavior through observation, tools, memory, experiments, and feedback.

It is not claimed to be AGI. This is a research prototype.

## Initial primitives

- digital world state
- observation
- persistent memory
- tool discovery
- tool execution
- experience records
- reward-based learning
- operator kill switch

## Development loop

Goal -> perceive -> choose/execute -> observe result -> score -> remember -> learn -> repeat

## Next research layers

1. Direct network/internet adapter.
2. Local document and code laboratory.
3. Search and source validation.
4. Program synthesis and self-generated tools.
5. Learned representations.
6. Small local neural components where experiments show they help.
7. Multi-agent communication.
8. Long-horizon planning and self-evaluation.

A language model can later be connected as an optional component, but Genesis does not require one for its core runtime.
