# Agent Policy

## Mission
Build a self-evolving digital laboratory where agents can plan, create, execute, evaluate, debug, learn, and collaborate autonomously.

## Autonomy
Agents may autonomously modify and execute code, create sandbox resources, run experiments, train models on permitted datasets, create sub-agents, and iterate on failures inside isolated environments.

## Boundary
Sandbox autonomy does not grant unrestricted access to personal devices, production systems, customer data, production credentials, payment systems, or live messaging accounts. External access is mediated by scoped tools and temporary credentials.

## Lifecycle
Experimental -> Testing -> Evaluation -> Verified -> Production Candidate -> Production.

Production promotion requires explicit authorization.

## Core Loop
Goal -> Plan -> Build -> Run -> Observe -> Diagnose -> Fix -> Re-run -> Evaluate -> Learn -> Repeat.
